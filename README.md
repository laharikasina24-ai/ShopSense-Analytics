# ShopSense Analytics

## Project Overview

ShopSense Analytics is a retail sales analytics project built using the Global Superstore dataset. The project focuses on data cleaning, SQL analysis, exploratory data analysis, and Power BI dashboard development to generate business insights.

## Dataset

Global Superstore Dataset

## Tools Used

* Python (Pandas)
* SQL
* Power BI
* GitHub

## Data Cleaning

* Checked missing values.
* Found missing values in Postal Code and retained them.
* Checked duplicate records (none found).
* Converted Order Date and Ship Date to datetime format.
* Created a new feature: Shipping Days.
* Saved cleaned dataset for analysis.
